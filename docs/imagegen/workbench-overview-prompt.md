## 可直接复制给图片生成模型的提示词

请为开源项目「Prompt Workbench · 提示词工作台」生成一张用于 GitHub README 顶部的中文产品总介绍图。

画布：横向 3:2，建议 1536×1024 或 2304×1536；不透明背景，PNG 输出。文字在整张图缩小后也应能清晰阅读。

设计风格：精致、温暖、清楚的产品快速上手信息图。依据真实启动页的深森林绿、暖米白纸色和朱红色按钮设计，辅以少量柔和金色。留白充足，阴影轻柔，中文字体清晰。参考 Agnes 介绍图的阅读顺序，设计属于本项目的原创画面，不复制其品牌或应用内容。

版式：顶部为产品标题与一句简介；左侧约占三分之二，展示一个浏览器工作台示意窗口；右侧约占三分之一，展示三个编号步骤卡片；底部为体验地址条。画面不要堆满长段文字，也不需要人物、机器人或复杂装饰。

顶部主标题逐字写为：
「提示词工作台｜快速上手」
副标题逐字写为：
「从一个念头，到一份可用的提示词」

左侧浏览器窗口使用本项目真实截图的视觉语言：深绿色侧栏、米白主工作区、朱红强调色。侧栏标识写「提示词」「工作台」。主要区域以四张简洁功能卡介绍真实能力，图标分别使用对话、文档、六轴雷达图、版本记录。功能卡文案逐字写为：

「需求访谈」
「逐问梳理 · 多选与补充」

「提示词生成」
「核对需求 · 手动生成」

「质量评审」
「六项维度 · 独立评分」

「版本迭代」
「回看记录 · 修改再生成」

这是功能介绍示意窗口，不要冒充真实截图。六轴雷达图只做功能示意，不显示虚构的总分或分项分数。若给雷达轴标注文字，使用「目标」「背景」「受众与场景」「约束」「输出要求」「可执行性」。

右侧三个步骤卡的文案逐字写为：

「1 打开工作台」
「访问在线体验地址」

「2 连接模型」
「填写模型服务与 API Key」

「3 访谈与生成」
「回答问题，手动生成提示词」

底部体验地址条逐字写为：
「体验地址：prompt-workbench-3xc.pages.dev」

底部小字逐字写为：
「原生 JavaScript · 无构建 · 浏览器本地保存」

要求：所有中文和网址准确、完整、易读。不要加入 Agnes 字样，不要添加图像生成、视频生成、云端同步、免费模型、团队协作等本项目没有的功能。不要显示 API Key、个人邮箱或其他私人信息。不要生成二维码。不要增加多余文案、版本号、许可证或水印。

## 输出与回传
