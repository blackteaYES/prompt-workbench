# 提示词完善工作台

主应用是一个纯浏览器端的提示词访谈与迭代工具。它会逐个询问需求细节；只有手动点击生成按钮后才生成提示词。页面使用原生 HTML、CSS 和 JavaScript，不需要 Python 后端或依赖安装。

## 启动

可直接打开 `static/index.html`。也可以从仓库根目录启动一个静态文件服务器：

```powershell
python -m http.server 8001 --directory static
```

然后访问 <http://127.0.0.1:8001>。静态服务器只负责提供网页文件，不处理模型请求或保存会话。建议始终使用同一个浏览器和网页地址，以便继续访问该来源下的本地数据。

## 模型配置

点击页面右上角的模型名称，设置 OpenAI 兼容接口或 Ollama 的 Base URL 和模型名称。可以获取模型列表，也可以手动填写；设置窗口提供连接测试。

工作区可分别选择访谈、生成和评审模型。点击对应模型卡片，可以搜索已获取的模型列表或自定义输入名称；默认跟随顶部的服务及模型，选择会保存在当前浏览器中。生成时可勾选由同一模型一起评分，也可先只生成提示词，之后选择其他评审模型单独评分。访谈已结束且模型提示现有信息足够时，可以直接生成；如果最新版本已包含当前信息，切换生成模型也可重新生成。

模型请求由浏览器直接发送到所选服务。OpenAI 兼容服务需要允许网页来源的跨域请求，并放行 `Authorization` 和 `Content-Type` 请求头。Ollama 需要在 `OLLAMA_ORIGINS` 中允许网页来源。例如，使用上面的静态服务器时，OpenAI 兼容服务应允许来源 `http://127.0.0.1:8001`，并允许 `GET`、`POST`、`OPTIONS` 以及 `Authorization`、`Content-Type` 请求头；换用其他地址时请改成实际网页来源。Ollama 通过 `OLLAMA_ORIGINS` 允许该来源。直接以 `file://` 打开时，浏览器可能发送 `null` 来源，部分服务会拒绝跨域请求，因此推荐使用静态服务器。

模型设置和 API Key 保存在当前浏览器的 IndexedDB（不可用时尝试本地存储）中。再次打开页面时无需重新输入密钥；输入框留空会沿用已保存密钥，输入新密钥则替换它，也可以在模型设置中清除。密钥不会显示回页面，但浏览器本地数据并未加密，共用设备请勿保存。模型请求会把提示内容和 API Key 发送给所配置的服务，请勿连接不可信的服务。

## 数据

会话、问答、反馈、提示词版本及模型设置保存在浏览器的 IndexedDB 中（不可用时尝试使用本地存储）。数据只属于当前浏览器配置和网页来源；清除浏览器站点数据会删除这些记录。

新评分按目标清晰度、背景完整度、受众与场景适配度、约束覆盖度、输出要求明确度、可执行性与验收标准六项评估。历史版本保留生成时保存的评分维度，不会被新维度改写。单独评分保存在该版本的评分记录中，包含模型、时间、评分依据和改进建议；不会改写提示词或覆盖原评分。仅生成提示词的版本显示“待评分”。

`demo/` 是独立的宝可梦图鉴原型，不属于主应用。需要刷新图鉴数据时，才在 `demo/` 中运行 `python sync_pokemon.py`；该脚本会重建生成数据。

## 界面与阅读

工作区左侧专注访谈，右侧通过“需求清单 / 完整提示词 / 质量评估”切换预览。需求清单默认折叠每道问题的完整回答，显示问题与回答摘要，并支持筛选已回答、待回答；点击展开时同步定位左侧问题，摘要让位给完整内容，避免重复展示。原始需求与版本反馈默认展开，也可手动收起。

清单底部仅提供“生成提示词”入口，在弹窗中确认生成模型和是否一起评分；尚未满足生成条件时仍可打开弹窗调整模型，确认按钮会说明条件并保持禁用。提示词与评估页顶部先选择版本，再查看对应内容。点击评分按钮，在弹窗中确认评审模型后追加评分。历史四项评分按原记录显示，重新评审可得到六项评分，不补造历史分数。生成后仍可继续访谈或提交版本意见，再生成新版本。

长回答选项和补充说明放在同一滚动区域，提交按钮保留在下方；未选择任何选项且未填写有效文字时，按钮禁用。对话、工作预览和提示词均支持放大查看，评分、历史版本和版本反馈可收起。

新消息、选项勾选、清单展开、页签滑动、弹窗、版本切换和复制操作提供动态反馈。等待模型时显示加载动画及已等待时间，不模拟模型内部进度；系统开启“减少动态效果”时会停用动画。

## 技术结构

- `static/index.html`：主应用页面
- `static/styles.css`：页面样式
- `static/app.js`：界面交互
- `static/browser-api.js`：浏览器存储及模型服务调用
- `demo/`：独立原型和数据工具
